# Steer ADE's agents from the phone

## Description

Approve or deny, prompts and `!` commands from the phone (piece 2b). Needs its own spec; first closes piece 1's forgeable-status limit.

## Outcome

From the phone the user answers what an agent is waiting for, without walking back to the Mac.

## Done when

1. Approve and deny a permission prompt from the phone; the terminal shows the same answer.
2. Send a prompt and a `!` command to a Claude Code tab and see the command's output on the phone.
3. A process in an ADE terminal can no longer forge a prompt the phone may approve.
4. Control is off per tab by default and asks for Face ID on the phone.
