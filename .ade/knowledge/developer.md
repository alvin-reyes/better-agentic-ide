- 2026-10-11: the test module of `bmadswitch.rs` already has a `section()` helper (for the journal); name new helpers apart from it.
- 2026-10-12: `SessionUsage` object literals live in three test helpers (`src/lib/__tests__/tokenUsage.test.ts`, `src/stores/__tests__/fleetStore.test.ts`, `src/components/__tests__/TokensPanel.test.tsx`); adding a required field fails `npx tsc --noEmit` until all three have it.
- 2026-10-14: `src-tauri` is now a Cargo workspace with member `ade-hook`; plain `cargo test` in `src-tauri` still runs only the root crate, and `src/hook_forward.rs` is compiled into both (via `#[path]`), so the helper's tests run there. A dev build needs `cargo build -p ade-hook` once, or Agent status reports the helper missing.
- 2026-10-14: serde_json here has no `preserve_order`, so any ADE write to a settings file re-sorts its keys; compare parsed values, not bytes, in round-trip tests.
- 2026-10-14: driving the real Claude Code for fixtures: python `pty.fork`, the trust dialog defaults to "No, exit" (send Down then Enter); `echo` runs without a prompt, `touch`/`python3 -c` prompt; `scripts/agent-status-check.sh` is the working driver.
- 2026-10-14: `pty.rs` has a source guard counting `thread::spawn(` (exactly one); new pty tests must not spawn threads there. `usage.rs` tests that set env vars would race other tests; prefer pure helpers (`lock_dir_of`).
- 2026-10-15: `mobile/` deps were installed with `npm_config_before=2026-10-01` (the two-week pin rule). `npx expo install` ignores it, because it asks the Expo API for the latest versions; take the ranges from `node_modules/expo/bundledNativeModules.json` instead. `npm install` passing doesn't mean `npm ci` will: `react-dom` has to be pinned to 19.2.3 or a fresh `npm ci` fails on ERESOLVE. To test the EAS case, copy `mobile/` and `packages/protocol` to a scratch dir with no `node_modules` above it. In the repo, the root `node_modules` hides missing peers.
- 2026-10-16: `relay/` has no date pin: after any `cargo update`, check each Cargo.lock package's crates.io `created_at` (full timestamp, not just the date: libc 0.2.190 slipped through a date-only check) against the two-week rule and `cargo update -p name@ver --precise` the new ones (story 2 had to pin hyper, mio, serde_json, smallvec, syn, tokio, unicode-ident, zerocopy, zeroize). tokio-tungstenite only answers pings while the socket is read, which is how the e2e test fakes a dead client.
- 2026-10-16: a fresh worktree has no `node_modules`. Root `npx tsc`/`vitest` resolve up to the main checkout's install, but `mobile/` doesn't: make `mobile/node_modules` a dir of symlinks to each entry of the main checkout's `mobile/node_modules`, except `@ade/protocol`, which must link to the worktree's `../../../packages/protocol` (the main one's link resolves to the main checkout's package).
- 2026-10-16: `packages/protocol/vectors/generate.mjs --check` runs inside `npm test` (vectors.test.ts). After changing any generated vector input, rerun `node packages/protocol/vectors/generate.mjs` and commit the JSON, or `npm test` fails.
- 2026-10-16: `generate.mjs` pins the SHA-256 of `vectors/cacophony-ik.json` (`CACOPHONY_SHA256`) and must reproduce it before writing anything; editing that excerpt means updating the constant. `noise.json` (~310 KB) is generated; `schedule.json` is hand-written, so a scheduler change means editing its expectations by hand in both runners' terms (Rust `relay/core/src/session.rs` tests, TS `session.test.ts`).
- 2026-10-16: `relay-core`'s session tests take 4-12 s (two 1,000-loop threaded tests). snow 0.10.0's source and `tests/vectors/cacophony.txt` are in `~/.cargo/registry/src/*/snow-0.10.0`. A mutant with `yield_now()` overstates what a test catches; mutate without it. `npm test` can flake once in `BoardPanel.test.tsx` under full-suite load; it passes alone.

A blocking-store test on a `current_thread` runtime can't rely on `tokio::time::timeout` (a blocked runtime never fires it): run the body on its own thread and `recv_timeout` from the test thread. `relay/e2e/tests/common/mod.rs` (`CountingStore`, `CaptureLog`) is shared by test files via `mod common;`.
- 2026-10-16: jsdom (cssstyle) turns a plain hex in `el.style` into `rgb(r, g, b)` but keeps a hex inside `repeating-linear-gradient(...)` as written, and does not expand `borderRadius` shorthand into the corner longhands; set the longhands if a test reads a corner.
- 2026-10-17: macOS has no `timeout` binary, so a mutation check that might hang needs the test's own `recv_timeout`; for `read_text_head_refuses_non_files`, mutate to `if meta.is_dir()` to reach the FIFO case (the folder case fails first otherwise). `src-tauri/src/watcher.rs` was not `rustfmt`-clean before Story 1, so don't reformat it wholesale.
