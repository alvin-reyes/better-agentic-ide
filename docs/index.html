Agent workflow

Draft. Run. Review. Repeat.

The loop you do a hundred times a day, without leaving the window.

1Draft the prompt before you send it

A scratchpad under every terminal for long, careful prompts. Send with one key, reuse from history and notes, dictate by voice, or paste a screenshot — its path goes along with the prompt.

  • Prompt chaining — split with ---; each step waits for the agent to go idle
  • Send Enter to answer "Proceed?" without leaving the pad
  • Your draft survives crashes and restarts

2Run agents side by side

Split panes and named tabs, 37 agent profiles for backend, frontend, DevOps, testing and Web3, and an orchestrator that turns a conversation into tasks and dispatches each to its own terminal.

  • Agent picker suggests the right profile for a task
  • 11 architects for AI automation and Web3 to brainstorm with — they record decisions as ADRs
  • Claude Code, Codex, Gemini CLI or Ollama
  • Notifications when an agent finishes

3Review what they wrote — with a click

Every file path an agent prints becomes a link once the file exists. Documents open in a live preview beside the terminal; code opens in a tab.

  • Markdown with tables, images and Mermaid diagrams
  • PDF, Word, images and HTML rendered in place
  • Safe by default — rendered documents can't run code

4See the whole fleet

ADE follows Claude Code's own transcripts, so every sub-agent — Explore, Plan, reviewers — shows up on a timeline as it starts and finishes, per terminal or across all of them, with running counts and estimated cost.

  • Swimlanes for 5 min, 15 min, 1 hour or all time
  • Jump straight to the pane an agent runs in
Smart contracts

From forge init to a reviewed deploy

Open a Foundry, Hardhat or Anchor project and press ⌘⇧K. ADE finds the project from any subfolder and puts the whole toolchain one click away.

Build, test, measure, analyze

Actions run in your terminal from the project root, so you see real output and can stop anything. The local chain gets its own tab and keeps running while you work.

  • Tests with traces, gas report, coverage and snapshots
  • Slither and Aderyn static analysis
  • Anvil, Hardhat node or solana-test-validator in one click
  • Solidity highlighting and clickable compiler errors

Read an ABI like a spec

Compiled artifacts open as read and write functions, events and errors — with the exact selectors and topic hashes the EVM uses. Click to copy one when you're decoding calldata or a revert. Anchor IDLs show instructions, accounts and error codes.

  • Only your contracts — forge-std and OpenZeppelin stay out of the list
  • Filter by name; Source shows the raw JSON

Test each function. Call it on a local chain.

The workbench gives each Foundry project its own tab. Compile with clickable errors, then run a single test, one contract's tests or all of them, and see gas, fuzz runs and the failure reason. Start Anvil, deploy with constructor arguments, and call any function.

  • ▶ Run on every test, and Traces for a -vvvv rerun
  • Events and reverts decoded, including custom errors with argument names
  • Local only: Anvil's unlocked accounts, with no keys and no broadcasting

Deploys you review first

Deploy actions type the command into the terminal and stop — you check the network and account, then press Enter. Foundry deploys use an encrypted keystore account; ADE never asks for, stores or syncs a private key.

forge script script/Deploy.s.sol --rpc-url "$RPC_URL" --account deployer --broadcast

Tabs, splits, each terminal's folder and scrollback, open files and your unsent draft are saved to disk within a second. Point ADE at a private git repo and your settings, notes, prompt history and Claude memory follow you.

FAQ

Questions, answered

Is ADE free?

Yes. It's open source under the MIT license. You bring your own agents — Claude Code, Codex and Gemini use your own accounts, and Ollama runs models locally.

Do I need Claude Code?

No — ADE is a full terminal and works with any CLI. Claude Code gets the most out of it, because the fleet view reads Claude Code's transcripts to show sub-agents.

Does ADE ever see my private keys?

No. Deploy actions only type a command for you to review, and Foundry deploys use an encrypted keystore account. ADE doesn't ask for, store or sync keys. Your Anthropic API key (used only by the orchestrator) stays on your machine and is stripped before anything syncs.

Which smart contract toolchains are supported?

Foundry and Hardhat for EVM chains, and Anchor for Solana. ADE detects the project from foundry.toml, hardhat.config.* or Anchor.toml, and picks up Slither and Aderyn if they're installed.

What gets synced between my machines?

Only what you choose, to a private git repo you own: settings, notes, prompt history, workspaces and orchestrator history, plus (optionally) your Claude memory. Each machine's terminal session stays on that machine, and scrollback is never pushed.

Which platforms does it run on?

macOS (Apple Silicon and Intel), Windows 10 and 11, and Linux (.deb or AppImage). It's a native Tauri app, so it's a small download with low memory use.
