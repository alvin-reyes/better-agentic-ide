Features

Everything around the agent, in one window

ADE is a real terminal first. Everything else is there so you stop switching apps while agents work.

Terminal

Tabs, splits and zoom — all from the keyboard

Named tabs, horizontal and vertical splits, one-key zoom, search with regex, and tabs you can pull into their own window without stopping what's running.

  • Sessions survive splits, tab switches and restarts
  • Record and replay any pane at 1×, 2× or 4×
  • Notifications when an agent finishes
claude — acme-api
➜ acme-api claude ⏺ I'll add idempotency keys to the webhook handler. ⏺ Write(src/webhooks.ts) ⎿ Wrote 48 lines ⏺ Write(tests/webhooks.test.mjs) ⏺ Bash(npm test) ⎿ ✔ ignores a repeated webhook id ⏺ Updated docs/plan.md — task 2 is done.
Clickable files

Click any file an agent writes

Paths in terminal output become links as soon as the file exists — Write(docs/plan.md), ./report.pdf, src/App.tsx:42. Documents open in the live preview beside the terminal; code opens in a tab.

  • Markdown with tables, images and Mermaid diagrams
  • PDF, Word, images and HTML rendered in place
  • Live refresh while the agent is still writing
Scratchpad

Write the prompt before you send it

A scratchpad under every terminal for drafting long prompts. Send with one key, keep a searchable history, save notes and templates, or dictate by voice.

  • Prompt chaining — split with --- and each step waits for the agent to go idle
  • Paste screenshots — the image path goes along with the prompt
  • Send Enter to answer an agent without leaving the pad
Fleet view

Every agent and sub-agent on one timeline

ADE follows Claude Code's transcripts, so every sub-agent your agents spawn shows up as it starts — per terminal or across all of them — with running counts and estimated cost.

  • Swimlanes for the last 5 min, 15 min, hour or all time
  • Jump straight to the pane an agent runs in
  • 26 agent profiles and an orchestrator that plans and dispatches tasks
Smart contracts

Foundry, Hardhat and Anchor, one key away

Open a contract project and ⌘⇧K gives you build, test, gas and coverage, Slither and Aderyn, a local chain in its own tab, and deploy commands typed for you to review — never run blind, never with a raw private key.

  • ABI viewer with read/write functions, events, errors and their selectors
  • Web3 agents — contract engineer, auditor, gas optimizer, Solana/Anchor
  • Solidity highlighting and clickable compiler errors
Auto-save & sync

Close it, crash it, switch machines — nothing lost

Tabs, splits, each terminal's folder and scrollback, open files and your unsent draft are saved to disk within a second. Point ADE at a private git repo and your settings, notes, prompts and Claude memory follow you.

  • Snapshots every 10 minutes, restorable from Settings
  • Syncs CLAUDE.md plus your commands, agents and skills
  • Private by design — API keys and scrollback never leave the machine

Orchestrator

Chat through a project, get tasks with owners and dependencies, then dispatch each into its own terminal with a generated spec.

BMAD personas

Install BMAD-METHOD into a project in one click, then launch the Analyst, PM, Architect, Developer or QA persona.

Browser tab

Keep your dev server open next to the agent building it — localhost:3000 in a tab.

Code editor

Monaco with syntax highlighting for quick fixes, and Mermaid files with a live diagram preview.

Safe rendering

Markdown and documents are sanitized, so a hostile README can't run code in the app.

Native and light

A Tauri app in Rust: small download, low memory, and a real PTY for every pane.
