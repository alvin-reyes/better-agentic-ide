02

Built for serious software engineering work

An agent will tell you it is finished. The question is who checks. ADE sets every project up with a methodology that answers that, and roles that cannot mark their own homework.

Done is a command, not an opinion

Every project agrees one verification command up front. A story is Done when it passes on that commit, with the output shown. Not when an agent says so.

No agent certifies its own work

The Developer writes the failing test first, then the code. QA judges the result and may not edit code or tests, because a verifier that repairs what it measures can make its own verdict come true.

An adversarial reviewer that cannot patch

It ships with a read-only tool allowlist on purpose: Read, Grep, Glob, Bash. It judges and reports. Widening it to unblock a story is how review stops meaning anything.

Nineteen roles, each with boundaries

Analyst through security engineer, SRE and release manager. Each one states what it owns, what it must not touch, and whose job the rest is, so parallel agents stop contradicting each other.

BMAD in every project, and actually used

75 files of tasks, checklists, templates and workflows. Eight roles name the ones that do their job, so the Scrum Master shards with create-next-story and QA traces criteria with trace-requirements instead of improvising both.

What they learn stays in your repo

A knowledge store per role, committed with the project. Shared contracts go to the context store where parallel agents read them. An update never overwrites either.

FAQ

Questions, answered

Is it really free?

Yes. Download ADE; nothing is locked.

How does licensing work?

It does not. ADE is MIT licensed: no keys, no accounts, no seats to count. Use it at work, fork it, ship your own build.

Which agents does it support?

Any CLI agent runs here, but ADE is built around Claude Code and goes deepest with it: sub-agents in .claude/agents/, a CLAUDE.md constitution, sub-agent lanes on the fleet timeline, and real spend read from its transcripts. Codex, Gemini and Ollama run side by side and show no cost, because they publish none.

How many agents can run at once?

As many as your machine and your provider's rate limits allow. Ten is what we test.

Does it store my keys?

API keys stay in your OS keychain, never synced. ADE never handles private keys.

Which platforms does it run on?

macOS (Apple Silicon and Intel) and Linux (.deb or AppImage). On macOS you can also run brew install --cask alvin-reyes/tap/ade. Windows support is coming soon.
