FAQ

Questions, answered

Is there a free trial?

Yes. Download ADE and use every feature for free while you evaluate it. There's no time bomb and nothing is locked.

How does licensing work?

It's on the honor system. There are no license keys and no DRM. If you keep using ADE after trying it, buy a license for each person who uses it.

Which agents does it support?

Claude Code, Codex and Gemini CLI, plus local models through Ollama. ADE is a full terminal, so any CLI agent runs in it. Claude Code gets the most out of the fleet view and tokens panel, which read its usage records.

Does it store my keys?

API keys stay on your machine and are never synced. ADE never asks for, stores or handles private keys: deploy commands are typed for you to review and use Foundry's encrypted keystore.

Which platforms does it run on?

macOS (Apple Silicon and Intel), Windows 10 and 11, and Linux (.deb or AppImage). On macOS you can also run brew install --cask alvin-reyes/tap/ade.
