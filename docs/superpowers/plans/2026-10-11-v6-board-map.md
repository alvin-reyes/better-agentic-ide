# v6 Board Map Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A v6 project's board panel shows a map of BMAD v6's four phases (each skill's docs with their status, the tickets, quick plans, retrospectives, loose work and the backlog) instead of ADE's five-stage board, which becomes v4-only.

**Architecture:** A new engine, `buildV6Map`, reads the v6 output folder through the existing `Fs` adapter and returns a `V6Map`. A table of doc kinds drives classification. Ticket logic is factored out of `buildBoardV6` into `v6Tickets` so the claimed and approval rules stay in one place. The panel's store holds a v4 `board` or a v6 `map`, and a new `V6MapView` draws the map, reusing the ticket `Row` and the "Needs attention" list. `buildBoardV6` and the v6 branches of the five-stage board are then deleted.

**Tech Stack:** TypeScript, React 18, zustand, vitest + @testing-library/react, Tauri 2 (no Rust changes).

**Spec:** `docs/superpowers/specs/2026-10-11-v6-board-map-design.md` (parent: `docs/superpowers/specs/2026-10-10-stage-board-panel-design.md`)

```ts
/**
 * The top-level `key: value` pairs of a Markdown file's frontmatter, for the
 * v6 board map.
 *
 * Lenient on purpose. The repo has no YAML library, and v6 docs hold nested
 * maps (UX design tokens) and free text with colons (run logs). The map needs
 * only top-level scalars, so everything else is skipped rather than parsed,
 * and a real doc never reads as broken. The one failure is an opening fence
 * that is never closed: then nothing after it can be trusted as either
 * frontmatter or body.
 */
export function readFrontmatter(text: string): Record<string, string> | null {
  const lines = text.replace(/^\uFEFF/, "").replace(/\r\n/g, "\n").split("\n");
  if (lines[0]?.trimEnd() !== "---") return {};
  const end = lines.findIndex((l, i) => i > 0 && l.trimEnd() === "---");
  if (end === -1) return null;

  const out: Record<string, string> = {};
  for (const line of lines.slice(1, end)) {
    // Column 0 only: an indented line belongs to a nested value.
    const m = /^([A-Za-z_][\w-]*):(.*)$/.exec(line);
    if (!m) continue;
    const value = m[2].trim();
    const quoted = /^(["'])(.*)\1$/.exec(value);
    out[m[1]] = quoted ? quoted[2] : value;
  }
  return out;
}
```

```ts
import { readTicketTree, type TicketTree } from "./bmadTicketTree";
import { ticketView } from "./ticketView";
import { findGates } from "./gateDiscovery";
import { parseGate, type Gate } from "./bmadGates";
import type { StoryView } from "./storyState";
import type { Fs } from "./bmadRuntime/fs";
import { joinPath, normalizePath } from "./bmadRuntime/paths";

/**
 * ADE's record that a person approved a ticket: one file per ref holding the
 * date. v6 has no human approval status (`ready-for-dev` is written by agents
 * when their own plan is done), so the human gate lives in `.ade/`, beside the
 * verification gates ADE also owns.
 */
export const APPROVALS_DIR = ".ade/approvals";

export interface V6Tickets {
  tickets: StoryView[];
  epics: { slug: string; title: string; refs: string[] }[];
  /** Gates whose ref matches no ticket. */
  unmatchedGates: Gate[];
  /** Gates for a ticket that has a newer gate. */
  supersededGates: Gate[];
  problems: string[];
}

// The two ways a project can have no tree to read. The map reports a missing
// initiative folder itself, so neither is a problem here.
const NO_TREE = /^(no active initiative\b|active initiative folder not found)/;

async function approvedRefs(projectRoot: string, fs: Fs): Promise<Set<string>> {
  const dir = joinPath(projectRoot, APPROVALS_DIR);
  if (!(await fs.exists(dir))) return new Set();
  return new Set(await fs.list(dir));
}

/** A draft ticket a person approved is approved, and may be dispatched. */
function withApproval(v: StoryView, approved: Set<string>): StoryView {
  if (v.state !== "draft" || !approved.has(v.story.id)) return v;
  return { ...v, state: "approved", dispatchable: true };
}

/**
 * The active initiative's tickets as board rows. "Done" is believed only with
 * a readable PASS or WAIVED gate from `.ade/gates/` behind it (`ticketView`,
 * the same distrust rule as v4), and a draft is approved only by a person's
 * file in `.ade/approvals/`.
 *
 * A tree that fails to read (a malformed `tickets.toml`) is a problem, not a
 * failure: the rest of the board still has something to show.
 */
export async function v6Tickets(root: string, fs: Fs): Promise<V6Tickets> {
  const projectRoot = normalizePath(root);
  const problems: string[] = [];
  let tree: TicketTree | null = null;
  try {
    tree = await readTicketTree(projectRoot, fs);
  } catch (e) {
    const message = e instanceof Error ? e.message : String(e);
    if (!NO_TREE.test(message)) problems.push(`Ticket tree could not be read: ${message}`);
  }

  // Gates are read regardless, so an orphan verdict still surfaces.
  const gates = (await findGates(projectRoot, "v6", fs)).map((g) => parseGate(g.file, g.yaml));
  const approved = await approvedRefs(projectRoot, fs);
  const tickets = (tree?.tickets ?? [])

    .sort((a, b) => a.story.id.localeCompare(b.story.id, undefined, { numeric: true }));

  const cited = new Set(tickets.map((v) => v.gate?.file).filter(Boolean));
  const spare = gates.filter((g) => !cited.has(g.file));
  return {
    tickets,
    epics: (tree?.epics ?? []).map((e) => ({
      slug: e.slug,
      title: e.title,
      refs: (tree?.tickets ?? []).filter((t) => t.epic === e.slug).map((t) => t.id),
    })),
    unmatchedGates: spare.filter((g) => !ids.has(g.storyId)),
    supersededGates: spare.filter((g) => ids.has(g.storyId)),
    problems: [...problems, ...(tree?.problems ?? [])],
  };
}
```

```ts
import type { Fs } from "./bmadRuntime/fs";
import { joinPath, pathBasename } from "./bmadRuntime/paths";
import { readFrontmatter } from "./frontmatter";

/**
 * What the v6 skills write, as the board map reads it. Every skill writes one
 * folder per run into the initiative, named by its prefix (`prd-shop/`), with
 * a main file and, for most, a status in some file's frontmatter. One table
 * keeps those facts together: the prefixes, main-file names and status files
 * below come from the vendored skills' customize.toml and SKILL.md.
 *
 * Status words are shown as the doc states them. Agents write them, so they
 * are labels, not gates.
 */

export type V6Phase = "analysis" | "planning" | "implementation" | "validation";
export const V6_PHASES: V6Phase[] = ["analysis", "planning", "implementation", "validation"];
export const PHASE_LABELS: Record<V6Phase, string> = {
  analysis: "Analysis",
  planning: "Planning",
  implementation: "Implementation",
  validation: "Validation",
};

export interface V6Doc {
  kind: string;
  label: string;
  /** The folder's or file's name after its prefix (`shop` for `prd-shop`). */
  name: string;
  /** The main file, project-relative; null when none exists. */
  path: string | null;
  /** As the doc states it, else "present" or "in progress"; "unreadable status" when it cannot be read. */
  status: string;
}

export interface V6Kind {
  kind: string;
  prefix: string;
  phase: V6Phase;
  label: string;
  /** Main-file candidates in order, relative to the folder; `<f>` is the folder's name. */
  main: string[];
  /** The file holding the status (relative, `<f>` substituted) and the keys to try; null when the kind has none. */
  status: { file: string; keys: string[] } | null;
  /** The word when the status file or key is missing. */
  missing: "present" | "in progress";
}

const own = (keys = ["status"]) => ({ file: "<f>.md", keys });
// Brainstorm and forge set their run log's status only when a run finishes.
const runLog = { file: ".memlog.md", keys: ["status"] };

export const V6_KINDS: V6Kind[] = [
  { kind: "brainstorm", prefix: "brainstorm-", phase: "analysis", label: "Brainstorm", main: ["brainstorm.html", "<f>.md"], status: runLog, missing: "in progress" },
  { kind: "forge", prefix: "forge-", phase: "analysis", label: "Forge", main: ["forge-report.html", "<f>.md"], status: runLog, missing: "in progress" },
  { kind: "research", prefix: "research-", phase: "analysis", label: "Research", main: ["<f>.md", "research-briefing.html"], status: own(), missing: "present" },
  { kind: "brief", prefix: "brief-", phase: "analysis", label: "Brief", main: ["<f>.md"], status: own(), missing: "present" },
  { kind: "prfaq", prefix: "prfaq-", phase: "analysis", label: "PRFAQ", main: ["<f>.md"], status: own(["status", "stage"]), missing: "present" },
  { kind: "prd", prefix: "prd-", phase: "planning", label: "PRD", main: ["<f>.md"], status: own(), missing: "present" },
  // The pointer doc is never finalized; bmad-ux marks DESIGN.md final.
  { kind: "ux", prefix: "ux-", phase: "planning", label: "UX", main: ["<f>.md", "EXPERIENCE.md", "DESIGN.md"], status: { file: "DESIGN.md", keys: ["status"] }, missing: "present" },
  { kind: "architecture", prefix: "architecture-", phase: "planning", label: "Architecture", main: ["<f>.md"], status: own(), missing: "present" },
  { kind: "spec", prefix: "spec-", phase: "planning", label: "Spec", main: ["<f>.md"], status: null, missing: "present" },
  { kind: "change", prefix: "change-", phase: "implementation", label: "Course change", main: ["<f>.md"], status: own(), missing: "present" },
  { kind: "walkthrough", prefix: "walkthrough-", phase: "validation", label: "Walkthrough", main: ["<f>.md"], status: null, missing: "present" },
  { kind: "test-summary", prefix: "test-summary-", phase: "validation", label: "Test summary", main: ["<f>.md"], status: null, missing: "present" },
];

export type DocResult = { doc: V6Doc; problem: string | null };

export function relativeTo(root: string, path: string): string {
  const prefix = root.endsWith("/") ? root : `${root}/`;
  return path.startsWith(prefix) ? path.slice(prefix.length) : path;
}

export async function isFile(path: string, fs: Fs): Promise<boolean> {
  if (!(await fs.exists(path))) return false;
  try {
    await fs.readText(path);
    return true;
  } catch {
    return false; // a directory, or unreadable
  }
}

export async function isDirectory(path: string, fs: Fs): Promise<boolean> {
  if (!(await fs.exists(path))) return false;
  try {
    await fs.list(path);
    return true;
  } catch {
    return false;
  }
}

/** The kind a folder's name says it is; null for anything else. */
export function classifyFolder(name: string): V6Kind | null {
  return V6_KINDS.find((k) => name.startsWith(k.prefix) && name.length > k.prefix.length) ?? null;
}

/** A status word from `path`'s frontmatter, or why it could not be read. A missing file or key is neither. */
async function statusFrom(path: string, keys: string[], fs: Fs): Promise<{ word: string | null; error: string | null }> {
  if (!(await fs.exists(path))) return { word: null, error: null };
  let text: string;
  try {
    text = await fs.readText(path);
  } catch (e) {
    return { word: null, error: `could not be read: ${e instanceof Error ? e.message : String(e)}` };
  }
  const fm = readFrontmatter(text);
  if (fm === null) return { word: null, error: "frontmatter is not closed" };
  for (const k of keys) if (fm[k]) return { word: fm[k], error: null };
  return { word: null, error: null };
}

function result(projectRoot: string, doc: Omit<V6Doc, "status">, statusPath: string | null, read: { word: string | null; error: string | null }, missing: string): DocResult {
  return {
    doc: { ...doc, status: read.error ? "unreadable status" : read.word ?? missing },
    problem: read.error && statusPath ? `${relativeTo(projectRoot, statusPath)}: ${read.error}` : null,
  };
}

export async function readFolderDoc(projectRoot: string, folder: string, kind: V6Kind, fs: Fs): Promise<DocResult> {
  const name = pathBasename(folder);
  const sub = (s: string) => s.replaceAll("<f>", name);
  let path: string | null = null;
  for (const candidate of kind.main) {
    const abs = joinPath(folder, sub(candidate));
    if (await isFile(abs, fs)) {
      path = relativeTo(projectRoot, abs);
      break;
    }
  }
  const statusPath = kind.status ? joinPath(folder, sub(kind.status.file)) : null;
  const read = kind.status && statusPath ? await statusFrom(statusPath, kind.status.keys, fs) : { word: null, error: null };
  return result(projectRoot, { kind: kind.kind, label: kind.label, name: name.slice(kind.prefix.length), path }, statusPath, read, kind.missing);
}

/**
 * A `plan-<slug>.md` outside any ticket: bmad-build's plan for work that has
 * no ticket. A plan whose `ticket` is set belongs to that ticket, which the
 * board already shows, so it is skipped.
 */
export async function readPlanFile(projectRoot: string, file: string, fs: Fs): Promise<DocResult | null> {
  let fm: Record<string, string> | null = {};
  let error: string | null = null;
  try {
    fm = readFrontmatter(await fs.readText(file));
    if (fm === null) error = "frontmatter is not closed";
  } catch (e) {
    error = `could not be read: ${e instanceof Error ? e.message : String(e)}`;
  }
  if (fm && fm.ticket) return null;
  const base = pathBasename(file);
  const doc = {
    kind: "plan",
    label: fm?.route === "oneshot" ? "Quick plan" : "Plan",
    name: base.replace(/^plan-/, "").replace(/\.md$/, ""),
    path: relativeTo(projectRoot, file),
  };
  return result(projectRoot, doc, file, { word: fm?.status || null, error }, "present");
}

/** An epic's retrospective, `<epic>/<epic>-retrospective.md`, with its verdict; null when it has none. */
export async function readRetrospective(projectRoot: string, epicFolder: string, fs: Fs): Promise<DocResult | null> {
  const slug = pathBasename(epicFolder);
  const file = joinPath(epicFolder, `${slug}-retrospective.md`);
  if (!(await isFile(file, fs))) return null;
  const read = await statusFrom(file, ["verdict"], fs);
  const doc = { kind: "retrospective", label: "Retrospective", name: slug.replace(/^epic-/, ""), path: relativeTo(projectRoot, file) };
  return result(projectRoot, doc, file, read, "in progress");
}
```

```ts
import type { Fs } from "./bmadRuntime/fs";
import { joinPath, normalizePath } from "./bmadRuntime/paths";
import { activeInitiativeName, outputFolder } from "./bmadRuntime/tickets";
import { readBacklogTree } from "./bmadTicketTree";
import { readFrontmatter } from "./frontmatter";
import { ticketView } from "./ticketView";
import type { Gate } from "./bmadGates";
import type { StoryView } from "./storyState";
import { v6Tickets } from "./v6Tickets";
import {
  classifyFolder, isDirectory, isFile, readFolderDoc, readPlanFile, readRetrospective, relativeTo,
  type DocResult, type V6Doc, type V6Phase,
} from "./v6Kinds";

export interface V6Map {
  /** `{output_folder}`, project-relative, for the watcher. */
  outputFolder: string;
  initiative: { title: string; folder: string } | null;
  initiativeState: "active" | "none" | "missing";
  docs: Record<V6Phase, V6Doc[]>;
  /** Docs and plans written with no initiative active, loose in `{output_folder}`. */
  loose: V6Doc[];
  epics: { slug: string; title: string; refs: string[] }[];
  tickets: StoryView[];
  backlog: StoryView[];
  unmatchedGates: Gate[];
  supersededGates: Gate[];
  problems: string[];
}

const byName = (a: V6Doc, b: V6Doc) => a.kind.localeCompare(b.kind) || a.name.localeCompare(b.name);

/**
 * Every doc and loose plan directly in `dir`, by kind. One level only: a doc
 * folder is probed for its main and status files, never walked, so a huge
 * `.working/` or `imports/` costs nothing. A symlinked folder is read like
 * any other at this depth and never followed further.
 */
async function scanFolder(projectRoot: string, dir: string, skip: (name: string) => boolean, fs: Fs): Promise<{ found: { phase: V6Phase; r: DocResult }[] }> {
  const found: { phase: V6Phase; r: DocResult }[] = [];
  for (const name of (await fs.list(dir)).sort()) {
    if (skip(name)) continue;
    const abs = joinPath(dir, name);
    if (/^plan-.+\.md$/.test(name)) {
      const r = await readPlanFile(projectRoot, abs, fs);
      if (r) found.push({ phase: "implementation", r });
    } else if (name === "deferred-work.md") {
      found.push({ phase: "implementation", r: { doc: { kind: "deferred", label: "Deferred work", name: "", path: relativeTo(projectRoot, abs), status: "present" }, problem: null } });
    } else {
      const kind = classifyFolder(name);
      if (kind && (await isDirectory(abs, fs))) found.push({ phase: kind.phase, r: await readFolderDoc(projectRoot, abs, kind, fs) });
    }
  }
  return { found };
}

async function initiativeTitle(folder: string, name: string, fs: Fs): Promise<string> {
  const doc = joinPath(folder, `${name}.md`);
  if (!(await isFile(doc, fs))) return name;
  return readFrontmatter(await fs.readText(doc))?.title || name;
}

/**
 * The board for a BMAD v6 project: a map of v6's four phases, not a sequence.
 * v6 says its phases are "not a mandatory sequence" and requires no skill, so
 * nothing here is a current stage; the human gates stay on the tickets.
 *
 * Only a config that cannot be read fails the build. A missing initiative
 * folder, a malformed ticket tree or an unreadable doc is a problem beside
 * whatever else could be shown.
 */
export async function buildV6Map(root: string, fs: Fs): Promise<V6Map> {
  const projectRoot = normalizePath(root);
  const out = await outputFolder(projectRoot, fs);
  const name = await activeInitiativeName(projectRoot, fs);
  const problems: string[] = [];
  const docs: Record<V6Phase, V6Doc[]> = { analysis: [], planning: [], implementation: [], validation: [] };
  const add = (phase: V6Phase, r: DocResult, into: V6Doc[] = docs[phase]) => {
    into.push(r.doc);
    if (r.problem) problems.push(r.problem);
  };

  let initiative: V6Map["initiative"] = null;
  let initiativeState: V6Map["initiativeState"] = "none";
  const folder = name ? normalizePath(joinPath(out, name)) : null;
  if (name && folder) {
    if (await isDirectory(folder, fs)) {
      initiativeState = "active";
      initiative = { title: await initiativeTitle(folder, name, fs), folder: name };
    } else {
      initiativeState = "missing";
      problems.push(`Initiative ${name} not found: ${relativeTo(projectRoot, folder)}`);
    }
  }

  const t = await v6Tickets(projectRoot, fs);
  problems.push(...t.problems);

  if (initiativeState === "active" && folder) {
    for (const { phase, r } of (await scanFolder(projectRoot, folder, () => false, fs)).found) add(phase, r);
    // Specs can sit inside the epic they specify; each epic may have a retrospective.
    for (const e of t.epics) {
      const epicFolder = joinPath(folder, e.slug);
      if (!(await isDirectory(epicFolder, fs))) continue;
      for (const n of (await fs.list(epicFolder)).filter((n) => n.startsWith("spec-")).sort()) {
        const kind = classifyFolder(n);
        const abs = joinPath(epicFolder, n);
        if (kind && (await isDirectory(abs, fs))) add("planning", await readFolderDoc(projectRoot, abs, kind, fs));
      }
      const retro = await readRetrospective(projectRoot, epicFolder, fs);
      if (retro) add("validation", retro);
    }
  }

  const loose: V6Doc[] = [];
  let backlog: StoryView[] = [];
  if (await isDirectory(out, fs)) {
    const skip = (n: string) => n === "backlog" || n === "inbox" || n.startsWith("initiative-") || n === name;
    for (const { phase, r } of (await scanFolder(projectRoot, out, skip, fs)).found) add(phase, r, loose);
    try {
      const tree = await readBacklogTree(projectRoot, fs);
      // No gates: a backlog ref is a file name, which `.ade/gates/` cannot key.
      backlog = (tree?.tickets ?? [])
        .map((ticket) => ticketView(ticket, []))
        .map((v) => ({ ...v, dispatchable: false }));
      problems.push(...(tree?.problems ?? []));
    } catch (e) {
      problems.push(`Backlog could not be read: ${e instanceof Error ? e.message : String(e)}`);
    }
  }

  for (const list of Object.values(docs)) list.sort(byName);
  loose.sort(byName);
  return {
    outputFolder: relativeTo(projectRoot, out),
    initiative,
    initiativeState,
    docs,
    loose,
    epics: t.epics,
    tickets: t.tickets,
    backlog,
    unmatchedGates: t.unmatchedGates,
    supersededGates: t.supersededGates,
    problems,
  };
}
```

`byName` sorts within a phase by kind, then name. The first test's Implementation order (`deferred` before `plan`) follows from that.

```tsx
import type { V6Map } from "../../lib/v6Map";
import { PHASE_LABELS, V6_KINDS, V6_PHASES, type V6Doc, type V6Phase } from "../../lib/v6Kinds";
import type { StoryView } from "../../lib/storyState";
import { GateProblems, Row, rowLabel, type BoardActions } from "./BoardView";
import { heading, muted, section } from "./boardStyles";

export interface V6MapViewProps {
  map: V6Map;
  error: string | null;
  actions: BoardActions;
  dispatched?: (v: StoryView) => boolean;
  dispatchUnavailable?: string | null;
}

const link = { background: "none", border: 0, padding: 0, color: "var(--accent)", cursor: "pointer", font: "inherit" } as const;

function DocRow({ doc, onOpen }: { doc: V6Doc; onOpen(path: string): void }) {
  return (
    <div data-doc={doc.kind} style={{ display: "flex", gap: 6, alignItems: "baseline" }}>
      {doc.path ? (
        <button type="button" data-open onClick={() => onOpen(doc.path!)} style={link}>{doc.label}</button>
      ) : (
        <span>{doc.label}</span>
      )}
      <span style={{ ...muted, fontSize: 11, flex: 1 }}>{doc.name}</span>
      <span data-status={doc.status} style={{ fontSize: 11, color: doc.status === "unreadable status" ? "var(--warning, #d29922)" : undefined }}>{doc.status}</span>
    </div>
  );
}

/** One phase: a row per doc of each kind, or a muted "none yet" line; then the phase's own extras. */
function Phase({ phase, docs, onOpen, children }: { phase: V6Phase; docs: V6Doc[]; onOpen(path: string): void; children?: React.ReactNode }) {
  const kinds = V6_KINDS.filter((k) => k.phase === phase);
  const others = docs.filter((d) => !kinds.some((k) => k.kind === d.kind));
  return (
    <section style={section}>
      <h3 style={{ ...heading, margin: "0 0 6px" }}>{PHASE_LABELS[phase]}</h3>
      {kinds.map((k) => {
        const mine = docs.filter((d) => d.kind === k.kind);
        return mine.length > 0
          ? mine.map((d) => <DocRow key={`${d.kind}:${d.name}`} doc={d} onOpen={onOpen} />)
          : <div key={k.kind} style={{ ...muted, fontSize: 11 }}>{k.label} · none yet</div>;
      })}
      {others.map((d) => <DocRow key={`${d.kind}:${d.name}`} doc={d} onOpen={onOpen} />)}
      {children}
    </section>
  );
}

function Tickets({ map, actions, dispatched, dispatchUnavailable }: Omit<V6MapViewProps, "error">) {
  if (map.tickets.length === 0) return <div style={{ ...muted, fontSize: 11, marginTop: 6 }}>No tickets yet.</div>;
  const rows = (refs: string[]) =>
    map.tickets.filter((v) => refs.includes(v.story.id)).map((v) => (
      <Row key={v.story.id} v={v} actions={actions} methodology="v6" dispatched={dispatched} dispatchUnavailable={dispatchUnavailable} />
    ));
  const grouped = new Set(map.epics.flatMap((e) => e.refs));
  const other = map.tickets.filter((v) => !grouped.has(v.story.id)).map((v) => v.story.id);
  return (
    <div style={{ marginTop: 8 }}>
      {dispatchUnavailable && actions.onDispatch && map.tickets.some((v) => v.dispatchable) && (
        <div style={{ ...muted, fontSize: 11, marginBottom: 6 }}>Dispatch unavailable: {dispatchUnavailable}</div>
      )}
      {map.epics.map((e) => (
        <div key={e.slug} style={{ marginBottom: 8 }}>
          <div style={{ fontWeight: 600, fontSize: 11 }}>{e.title}</div>
          {rows(e.refs)}
        </div>
      ))}
      {other.length > 0 && <div><div style={{ fontWeight: 600, fontSize: 11 }}>Other</div>{rows(other)}</div>}
    </div>
  );
}

/** Backlog tickets: read-only, with no gate behind them. Clicking the title opens the leaf. */
function BacklogRow({ v, onOpen }: { v: StoryView; onOpen(path: string): void }) {
  return (
    <div data-backlog={v.story.id} style={{ display: "flex", gap: 8, alignItems: "baseline", padding: "2px 0" }}>
      {v.story.file ? (
        <button type="button" onClick={() => onOpen(v.story.file!)} style={{ ...link, flex: 1, textAlign: "left", color: "inherit" }}>{v.story.title}</button>
      ) : (
        <span style={{ flex: 1 }}>{v.story.title}</span>
      )}
      <span style={{ fontSize: 11, color: rowLabel(v) === "claimed" ? "var(--warning, #d29922)" : undefined }}>{rowLabel(v)}</span>
    </div>
  );
}

function qaSummary(tickets: StoryView[]): string | null {
  const count = (label: string) => tickets.filter((v) => rowLabel(v) === label).length;
  const [passed, waived, claimed] = [count("done ✓"), count("waived"), count("claimed")];
  return passed + waived + claimed === 0 ? null : `QA gates: ${passed} passed, ${waived} waived, ${claimed} claimed`;
}

/**
 * A v6 project's board: a map of v6's four phases. v6 says its phases are not
 * a sequence, so there is no current stage and no Next or Back; the human
 * gates (Approve, Dispatch, the QA gate, claimed) stay on the ticket rows.
 */
export default function V6MapView({ map, error, actions, dispatched, dispatchUnavailable }: V6MapViewProps) {
  const active = map.initiativeState === "active";
  const summary = qaSummary(map.tickets);
  return (
    <div style={{ overflowY: "auto", flex: 1, fontSize: 12 }}>
      {error && <div role="alert" style={{ ...section, color: "var(--error, #f85149)" }}>Could not refresh: {error}</div>}
      <div style={{ ...section, fontWeight: 600 }}>
        {active && map.initiative ? map.initiative.title
          : map.initiativeState === "missing" ? "Initiative not found"
          : <span style={{ ...muted, fontWeight: 400 }}>No active initiative. Set one with the bmad skill.</span>}
      </div>
      {active && V6_PHASES.map((phase) => (
        <Phase key={phase} phase={phase} docs={map.docs[phase]} onOpen={actions.onOpen}>
          {phase === "planning" && <div style={{ ...muted, fontSize: 11, marginTop: 4 }}>{map.epics.length} epics, {map.tickets.length} tickets</div>}
          {phase === "implementation" && <Tickets map={map} actions={actions} dispatched={dispatched} dispatchUnavailable={dispatchUnavailable} />}
          {phase === "validation" && summary && <div style={{ fontSize: 11, marginTop: 4 }}>{summary}</div>}
        </Phase>
      ))}
      {map.loose.length > 0 && (
        <div style={section}>
          <div style={heading}>Not in an initiative</div>
          {map.loose.map((d) => <DocRow key={`${d.kind}:${d.name}`} doc={d} onOpen={actions.onOpen} />)}
        </div>
      )}
      {map.backlog.length > 0 && (
        <div style={section}>
          <div style={heading}>Backlog</div>
          {map.backlog.map((v) => <BacklogRow key={v.story.id} v={v} onOpen={actions.onOpen} />)}
        </div>
      )}
      <GateProblems unmatchedGates={map.unmatchedGates} supersededGates={map.supersededGates} problems={map.problems} />
    </div>
  );
}
```

```markdown
The **stage board** (*View: Toggle stage board*, {% include key.html mac="⌘⇧Y" other="Ctrl+Alt+Shift+Y" %}) is a panel beside your terminals for the project of the active pane. It refreshes as agents write files.

On a **v6** project it is a map of BMAD v6's four phases: Analysis, Planning, Implementation and Validation. v6 runs its skills in any order, so there is no current stage. Each phase lists the documents its skills wrote in the active initiative (brainstorms, briefs, PRDs, UX, architecture, specs and so on), each with the status its own file states, and "none yet" for a kind with none. Click a document to open it. Implementation holds the tickets, grouped by epic, and the quick-flow plans; Validation holds a count of QA gate results and each epic's retrospective. Work done with no initiative active, and the backlog, are listed below the phases.

On a **v4** project it shows where the project is in BMAD's five stages, which plan documents exist, and every story, and you move the project's stage with **Next** and **Back**. Next appears only once the current stage's documents are on disk. A project that has never had its stage set follows its files until you click **Track stage**.

On both, a story or ticket that says it is done without a passing QA gate shows as **claimed**, and a waiver always shows its reason. You can **Approve** a draft and **Dispatch** an approved story or ticket to a developer agent in a new tab.
```
