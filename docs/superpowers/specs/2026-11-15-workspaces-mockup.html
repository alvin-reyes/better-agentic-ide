Mockup for 2026-11-15-workspaces-ux.md, draft 2. Self-contained: no network, invented names and paths. Pick a scenario on the right, then click or use the keys. Everything tagged S2 belongs to slice 2. Scenarios whose behaviour waits on an answer from the product manager name the question (P3, P13 to P19) in their caption and draw the recommended case. Built against PRD F4 revision 3.10 and the proposed design's revision 4; slice S0's line in Settings → Sync is the scenario “Settings → Sync: a store was skipped” (spec section 26).

The tab bar shows no workspace mark: a workspace tab opened by Open Hub looks like F2's hub tab (◇ Agent hub), one opened from a hub folder looks like a plain tab. The file browser and the palette are where a workspace shows.
