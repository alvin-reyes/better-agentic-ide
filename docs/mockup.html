The window title is “Payments API — Better Terminal” (the bundle's product name, read at run time). On macOS the menu item is also in the app menu (after About Better Terminal) and the Dock menu. On Windows it's in the system menu (Alt+Space) and the jump list. On Linux it's in this header menu and the desktop action. The jump-list task and the desktop action run better-terminal --open-engagements (ADR 0024) and exist only in builds with F1 compiled on. “Your main Better Terminal” names the default profile (owner's decision, 2026-11-08; §2). All platforms have it in the command palette. The header shows the engagement's name only, never the client.
